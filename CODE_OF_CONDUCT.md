# Code of Conduct

## The short version

Be decent. Argue with the code, the physics, or the reasoning — never with the person.

## Expected behaviour

- Assume good faith.
- Bring evidence. "This render looks wrong" is a start; "this render looks wrong,
  here's the parameter set and what the physics predicts instead" is a contribution.
- Accept that "no" is a legitimate answer to a proposal, and that it should come
  with a reason.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, sustained disruption, or
publishing others' private information.

## Scope

Applies to issues, pull requests, and any space where someone is representing the
project.

## Enforcement

Violations can be reported to the maintainer via a private message on GitHub
(open a security advisory or contact directly — see [SECURITY.md](SECURITY.md)
for the private reporting channel). Reports are handled discreetly.
